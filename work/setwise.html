SETWISE · TOKENIZED ASSETS · ORIGINAL CENO PROTOCOL

An original Ceno protocol for tokenized financial assets.

In development RWA INFRASTRUCTURE PROTOCOL DESIGN ROUTING GOVERNANCE SMART-CONTRACT SECURITY
01 Context

Tokenized financial assets reach markets through many issuers, in many forms, across more than one chain. Discovery, pricing and execution for those assets are still handled as separate problems.

Setwise treats them as one market-infrastructure problem.

02 Ceno's role

Setwise is an original Ceno protocol — designed and built from first principles rather than adapted from an existing DEX.

I am carrying the protocol from market modelling through contracts, routing and the interfaces around them.

03 What is being built

The protocol scope, under active development.

  • Multi-issuer market modelling
  • Tokenized asset discovery
  • Portfolio-style products
  • Market data across sources and venues
  • Multi-source execution
04 Technical depth
  • Routing and RFQ execution across sources
  • Cross-chain settlement
  • Governance mechanisms for issuer and portfolio flows
  • Security controls across contracts, permissions and settlement
05 Status

In development

A simplified version of the protocol is in development. The IN DEVELOPMENT label stays on Setwise until the public launch is live.

06 Links

Public links — live product, source code and documentation — are published at launch. Until then this page is the reference.
